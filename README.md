# Markdown to Interactive HTML Converter

[![Python Version](https://img.shields.io/badge/python-3.7%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Превратите ваши папки с Markdown-файлами в единый, самодостаточный HTML-файл. Этот инструмент создает интерактивную документацию или базу знаний, похожую на Obsidian, с удобной навигацией и темной темой. Идеально для портативных заметок или документации без веб-сервера.

## Возможности

Скрипт рекурсивно обходит указанную директорию, находя все `.md` файлы. Он парсит **GitHub Flavored Markdown**, включая таблицы, списки задач и блоки кода с подсветкой синтаксиса (используя Pygments).

Главная особенность — **интерактивная навигация**. В левой части генерируется всплывающая боковая панель, отображающая иерархию ваших папок и файлов (папки раскрываются). Нажатие на файл в панели или на **внутреннюю ссылку** в тексте загружает его содержимое динамически, без перезагрузки страницы. Поддерживаются как стандартные Markdown-ссылки (`[текст](путь.md)`), так и **Wiki-ссылки** Obsidian (`[[Файл]]`, `[[путь/Файл]]`, `[[Файл|Алиас]]`). Скрипт пытается разрешить эти ссылки; ненайденные помечаются визуально.

Весь необходимый HTML, CSS (имитирующий темную тему Obsidian) и JavaScript встроены в **один выходной файл**. Управление осуществляется через простой интерфейс командной строки.

## Требования и Установка

Вам понадобится **Python 3.7+**. Установите необходимые библиотеки:

```bash
pip install markdown pygments Markdown-Checklist
```

## Использование

Запустите скрипт из командной строки, указав входную директорию и имя выходного файла:

```bash
# Обязательные аргументы
python md_to_html_converter.py -i ./путь/к/заметкам -o документация.html

# С дополнительными опциями
python md_to_html_converter.py \
    --input-dir ./мои_проекты \
    --output-file проект_доки.html \
    --root-doc README.md \
    --title "Документация Проекта"
```

**Аргументы:**

*   `-i`, `--input-dir`: **(Обязательно)** Папка с Markdown-файлами.
*   `-o`, `--output-file`: **(Обязательно)** Имя выходного HTML.
*   `-r`, `--root-doc`: (Опционально) Какой файл показать при загрузке (относительный путь).
*   `-t`, `--title`: (Опционально) Заголовок HTML-страницы.

## Кастомизация и Ограничения

Внешний вид можно настроить, отредактировав CSS-стили прямо в переменной `CSS_STYLES` скрипта.

Текущая версия не включает поиск по тексту. Ссылки на локальные изображения могут не работать, если HTML-файл перемещен отдельно от них. Обработка очень большого количества файлов может быть медленной. Продвинутые функции Wiki-ссылок (на заголовки/блоки) не поддерживаются.
